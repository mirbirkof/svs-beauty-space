# Ціни волосся: робота + матеріал за довжиною (крок 0, 04.11)

Джерело — жива CRM (services.price), таблиці service_procedures / service_length_variants (міграція 319).
Ціни НЕ змінювались: чекаємо скріни прайсу від Босса. Пара «робота + матеріал» — тільки з однієї довжини.
«Клієнт бачить» — те, що показує мініап у плитці довжини і бот у списку послуг.
Картка мініапу = «від <мінімум по довжинах> ₴ · робота + матеріал».

## Що звірити зі скрінами прайсу (не вгадано, лишено як є)

1. Біовирівнювання — два набори. В процедуру взято набір «(до N см)» 2400/3200/3900/4600 як РОБОТУ
   + «матеріал … (до N см)» 600/800/1100/1400 → клієнт бачить 3 000 / 4 000 / 5 000 / 6 000.
   Другий набір «… довжина робота» 2000/2500/3050/3700 + «… довжина матеріал» 900–2625 сховано з мініапу як дублі (#22–#44, active не чіпали).
   Якщо «(до N см)» уже включає матеріал — клієнт бачить завищену суму; виправляється в CRM-таблиці «Ціни волосся» (режим матеріалу → «включено»), без коду.
2. «курс біовирівнювання» 7000 (#74) — окрема послуга, в процедуру не входить, показується як є.
3. «Біозавивка 3-4 довжина (робота)» 3000 (#43) — пари-матеріалу в CRM немає; показується «3 000 ₴ + матеріал за фактом».
4. Фарбування «без барвників» (#164–175, #185–193) — матеріал «за фактом» (у CRM ціни барвника нема).
   Конфліктні набори: #169/171/173/175 «N довжина + стрижка» 900/1050/1200/1200 проти #190–193 «+ стрижка N довжина» 1150/1150/1300/1150 (4-та дешевша за 3-тю).
5. «Фарбування в один тон» #178/180 (950/1100) проти «без врахування матеріалів» #179/181 (900/1000) — різниця 50–100 ₴ замала для матеріалу; незрозуміло, що з них що.
6. Полірування: #135 1000 без довжини проти #136/#137 по 1500.
7. Мелірування: #80/98, #81/99, #100/96/16, #82/97/17 — різні ціни за ту саму довжину; у процедури не зведено.
8. Холодне відновлення — матеріал-дублі #198/#203/#208 НЕ деактивовано (ціна та сама, але назва без дужок — лишено на рішення);
   у мініапі вони сховані як аліаси процедури.
9. Деактивовано 22 точні дублі (та сама назва + ціна) — бекап backups/hair-dups-0411.json, повернення: active=true за id.
